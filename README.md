NaviSense Smart Indoor Navigation System — XML/Java UI starter

This is a simple Android Studio Java + XML prototype based on the uploaded NaviSense proposal.
It is not a Flutter project, so use it for the MAD XML UI task only if your instructor accepts Java/XML.

How to use:
1. Create an Empty Views Activity project in Android Studio (Java).
2. Use package name: com.example.navisense
3. Replace/add the files in this starter into the matching app/src/main folders.
4. Ensure the app module namespace/applicationId is com.example.navisense.
5. Run on an emulator or phone.

Implemented as UI prototype:
- Dashboard / shop search
- QR scan placeholder screen (camera scanning not integrated)
- Facilities list
- AR navigation preview (real ARCore not integrated)
- Friend location share/trace placeholder
- Simple screen-to-screen navigation

Important: Do not claim real QR scanning, live location sharing, offline routing, or AR is complete. These screens are placeholders for Task 1.
